# Sunshine cursor settings

This addition preserves the existing Vue/Bootstrap configuration interface. Runtime appearance remains owned by sunshine.css and theme.js; Checkbox.vue owns checkbox labels, descriptions and enabled/disabled values. No visual tokens change.

The macOS-only Advanced option uses the existing config_tabs.json model, Checkbox.vue control and en locale strings. The existing configuration save/restart workflow applies. Cursor capture defaults off, matching the companion Moonlight local pointer default. Help explains duplicate pointers and restoring remote cursor shapes. Other platforms retain their existing capture behavior.
